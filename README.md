# Internship & Job Hub

A curated dashboard of underclassmen internships (Summer 2027), tech internships, and entry-level IT/networking/hardware/security opportunities.

- **Live Site**: https://yuuki-burleigh.github.io/internship-hub/
- **Categories**: Internships & Real Entry-Level Jobs
- **Filters**: Underclassmen programs, Summer 2027, Tech tags (Network, Security, Cloud/Infra, Hardware, IT Support)
- **Actions**: Direct application links + automated tailored résumé generation powered by GitHub Actions in `job-hub`.
